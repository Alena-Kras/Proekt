# ☕ Анализ продаж кофейни (Дипломный проект)

## 📌 Описание проекта
Данный проект представляет собой комплексный анализ данных о продажах кофейни для выявления ключевых факторов, влияющих на выручку и поведение клиентов. Работа включает в себя полный цикл обработки данных: загрузку и очистку сырых данных, создание новых признаков (Feature Engineering), разведочный анализ (EDA), а также построение интерактивного дашборда для визуализации результатов.

## 🛠 Используемые технологии
- **Python 3** (Pandas, NumPy, Matplotlib) — для обработки и анализа данных.
- **Jupyter Notebook** — среда для проведения анализа.
- **Tableau Desktop** — для создания интерактивного дашборда.
- **PowerPoint** — для оформления презентации проекта.
- **GitHub** — для хранения и версионирования проекта.

## 📂 Структура проекта
| Файл | Описание |
|------|----------|
| `Coffee Shop Sales.csv` | Исходные сырые данные о продажах кофейни |
| `customers.csv` | Данные о клиентах кофейни |
| `cofee_sales.ipynb` | Jupyter Notebook с полным кодом обработки и анализа данных |
| `Проект(графики).twbx` | Графики в Tableau |
| `Презентация проекта.pptx` | Презентация с результатами проекта |
| `.gitattributes` | Служебный файл Git |

## 📊 Ключевые выводы (Insights)
1. **Пиковые часы продаж** — наибольшая выручка приходится на утренние часы и выходные дни.
2. **Популярные категории** — кофе и выпечка составляют основную долю продаж.
3. **Постоянные клиенты** — обеспечивают значительную часть выручки, что подтверждает необходимость программы лояльности.
4. **Сезонность** — наблюдаются колебания спроса в зависимости от времени года.
5. **Средний чек** — позволяет оценить эффективность допродаж и акций.

## 📈 Как воспроизвести проект
1. **Запуск кода (Python):**
   - Установите зависимости: `pip install pandas numpy matplotlib`
   - Откройте `cofee_sales.ipynb` в Jupyter Notebook или JupyterLab.
   - Выполните ячейки последовательно для воспроизведения анализа.
2. **Визуализация (Tableau):**
   - Откройте файл `Проект(графики).twbx` в программе Tableau Desktop или Tableau Reader.
   - Для обновления данных подключите исходные CSV-файлы через **Data Source** (Источник данных).
3. **Презентация:**
   - Ознакомьтесь с `Презентация проекта.pptx` для краткого обзора результатов.
